## **ZKSOCIAL**  
Leverages zkTLS to privately prove ownership of Twitter and Telegram usernames directly on-chain while preserving user privacy. Integrates a Starknet Wallet SDK to create a unique wallet based on parameters derived from these platforms.

The system initially allows verified humans to onboard via Twitter and Telegram, followed by a 2:1 referral model where each user can invite two verified participants. Once established, it serves as a decentralized Proof-of-Personhood.

Users can also generate session keys from this wallet to securely authenticate on Twitter, Telegram, or compatible apps, ensuring privacy, interoperability, and decentralization.
